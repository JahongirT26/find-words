# Language Game

A React application for learning foreign words through a memory matching game.

## Features

* Match words with corresponding images
* Track mistakes and remaining lives
* Game over and victory states
* Results page with leaderboard
* Custom React hook for game logic
* Webpack configuration with development and production modes

## Technologies

* React
* JavaScript (ES6+)
* Webpack
* Babel
* CSS

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run start
```

## Build for Production

```bash
npm run build
```
